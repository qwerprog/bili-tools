## 变更说明

### 1. 新增终端交互式评论浏览器 (`bit video comments <VIDEO> -i`)
基于纯 `crossterm` 实现的全功能终端交互式评论浏览与互动界面（TUI），无需离开终端即可高效浏览与管理视频评论区：

```bash
# 打开视频评论区交互式浏览器（默认按热度排序）
bit video comments BV1xxxxxxxxx -i

# 指定排序或从某条根评论楼中楼进入
bit video comments BV1xxxxxxxxx -i --sort time
bit video comments BV1xxxxxxxxx -i --root 1234567890
```

- **流畅导航与楼中楼折展**：支持 `hjkl` 及方向键上下浏览、展开或折叠楼中楼子回复列表，并在超过预加载条目时按 `Enter` / `→` 按需拉取更多二级回复。
- **实时评论互动与即时回显**：支持 `Shift+L` 点赞/取消点赞、`r` 回复当前光标评论、`c` 直接评论视频、`d` 删除本人评论（带二次确认）；发表评论或回复后即时插入本地视图并刷新，无需退出重进。
- **站内搜索、翻页与排序**：支持 `/` 关键字搜索（`n`/`p` 逐条跳转匹配评论、`Enter` 定位、`Esc` 返回原位置）、主评论列表 `n`/`p` 翻页与 `s` 切换按热度/按时间排序。
- **状态指示与运行保护**：底部状态栏通过绿/红圆点（`●`）直观区分已登录（可写）与游客（只读）状态；在 `--json` 或非交互式终端（管道）环境下提前报错退出，不触发多余网络请求。

### 2. 默认多行树状评论排版与 `--compact` 紧凑模式
全面重构 `bit video comments` 的终端输出排版，默认即可完整阅读长评论与热评上下文：
- **多行树状排版**：完整保留自动换行正文与内嵌热评子回复（不再在 36 列或单行处截断），清晰展示树状连线与 `[置顶]`、`[UP]`、`Lv.X`、IP 属地、`已赞`、`[UP主觉得很赞]`、`[UP回复]`、`[🖼 图片 ×N]` 等徽标与 `--root <RPID>` 展开提示。
- **紧凑表格回归选项**：保留旧版单行表格排版作为 `--compact` 可选参数；原有 `--full` 参数保留并与默认值等价，保持向后兼容。

### 3. `--json` 评论数据精简与 `--raw` 原始模式
- **精简结构化 JSON（默认）**：移除 `avatar_item`、`fallback_layers`、`user_sailing`、`vip`、`emote` 等约 90% UI 装扮冗余字段，改以类型化字段（`pictures`、`reply_control`、`up_action`、`upper`、`top`）呈现核心评论数据，大幅降低脚本管道与 AI Agent 的上下文开销。
- **原始上游返回（`--json --raw`）**：保留上游完整 JSON 载荷，满足需要读取装扮或原始扩展字段的场景（独立使用 `--raw` 不配 `--json` 会明确提示错误）。

### 4. 新增 B 站字幕轨上传、查询与删除（by @lanbingyue1 in #1）
补齐字幕轨上传侧管理能力，支持将本地 SRT 字幕转换为 B 站 BCC 格式并提交至指定稿件分P：

```bash
# 提交字幕到指定分P（--draft 仅存草稿，--dry-run 离线转换不联网，--no-verify 跳过回查）
bit video subtitle-upload BV1xxxxxxxxx sub.zh.srt --lang zh -p 1

# 查询分P或全账号字幕轨（支持 --status all|draft|published|deleted 与 --list-page 分页）
bit video subtitle-list BV1xxxxxxxxx -p 1 --status all
bit video subtitle-list --status deleted --list-page 1

# 删除字幕轨（软删除，--json / 非 TTY 需显式 -y）
bit --json -y video subtitle-delete BV1xxxxxxxxx --id <SUBTITLE_ID> -p 1
```

- **客户端 SRT → BCC**：自动去 BOM、兼容 CRLF/CR 与空白分隔行、按小数位数解析毫秒、移除 `<...>` 样式标签，并先按 `0.01s` 舍入再执行时间轴单调递增与最小时长修正。
- **语言码显式归一化**：白名单为 `en`、`zh`、`zh-Hant`、`ja`、`ko`，显式支持 `zh-Hans`/`zh-CN` → `zh`、`zh-TW`/`zh-HK`/`zh-MO` → `zh-Hant`、`en-US` → `en`、`ja-JP` → `ja`、`ko-KR` → `ko`，非法值在发请求前直接报 `Input`。
- **落库复核与中断保护**：提交后轮询 `author/list` 第 1 页确认新版本落库（按真实时间窗口控制超时并容忍单次瞬时失败，也支持 `--no-verify` 跳过）；轮询与批量删除间隔复用 `sleep_interruptible` 支持 `Ctrl+C` 即时退出。
- **安全与完整过滤**：`subtitle-list` 全账号查询按状态完整翻页后再分页并返回 `matched_total`；`subtitle-delete` 校验所有 ID 归属目标 `cid` 并在发请求前完成非交互 `-y` 门禁检查。

### 5. 新增稿件元数据编辑、活动标签绑定与 4:3 封面支持（by @Maybe3141 in #2, #3）
补齐已投递稿件的增量编辑与创作中心活动投稿链路：

```bash
# 查询当前分区或关键词对应的创作中心活动/话题 (topic_id / mission_id)
bit video topics --tid 231 --activity-only
bit video topics -k "活动关键词"

# 投稿时同时指定 16:9 / 4:3 封面并绑定官方活动标签
bit video upload demo.mp4 --title "标题" --tid 171 --tag "工具,CLI" --cover c16x9.png --cover43 c4x3.png --topic "活动话题名"

# 增量编辑已有稿件元数据（不重传视频，未指定字段与分P列表保持原值）
bit video edit BV1xxxxxxxxx -t "新标题" --desc "新简介" --cover43 c4x3.png --topic "活动话题名"
```

- **4:3 推荐流封面（`--cover43`）**：`video upload` 与 `video edit` 均支持上传本地 `jpg`/`png`/`webp` 或传入远程 `https` URL 指定 4:3 封面（`video edit` 传 `--cover43 ""` 可清除）。
- **增量元数据编辑（`video edit`）**：支持修改 `--title`、`--tid`、`--tag`、`--topic`、`--topic-id`、`--mission-id`、`--desc`、`--copyright`、`--source`、`--cover`、`--cover43`、`--dynamic`、`--no-reprint`，抽象 `ArchiveEditPatch` 统一编辑载荷，并修复编辑时默认保留原稿件 `topic_id`、`mission_id`、`human_type2` 与对象形态 `recreate.switch`。
- **活动标签查询与绑定（`video topics` / `--topic`）**：对接 `/x/vupre/web/topic/type` 与 `/x/vupre/web/topic/search`，自动解析 `topic_id` / `mission_id` 并将活动名置顶补入标签（遵守 10 个标签上限），同时校验 `topic_id`/`mission_id` 合法范围与版权/禁转联动。

### 6. 构建兼容性、公共组件与文档同步
- **Windows 调试构建与栈优化**：新增 `build.rs` 为 Windows debug 构建放宽主线程栈至 8MB（兼容 MSVC `/STACK` 与 MinGW `-Wl,--stack`），并将 `VideoUploadArgs` / `VideoEditArgs` 装箱降低命令枚举栈帧占用。
- **UI 公共组件复用**：抽取宽字符安全的 `slice_input_window`（供直播聊天与评论 TUI 复用）及 ANSI 感知宽度计算、安全截断与选中行背景高亮辅助函数。
- **测试与文档同步**：补充评论 TUI、字幕轨管理、4:3 封面、稿件编辑与活动标签绑定全套单元测试与 e2e 测试，同步更新 `README.md` 与 Antigravity 插件文档（`SKILL.md`、`commands.md`、`AGENTS.md`）。
