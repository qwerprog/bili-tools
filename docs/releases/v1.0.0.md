## 核心亮点

`bili-tools (bt)` `v1.0.0` 是一次全功能跨代升级：从单一的直播开播工具箱重构为涵盖**视频投稿、视频/番剧下载、直播推流/聊天室/录播、社区发现与个人数据管理**的一站式 B 站命令行工具箱（12 大顶层模块，支持全量 `--json` 脚本集成）。

## 视频投稿与创作中心

- 新增 `bt video upload`（别名 `up`）：支持 UPOS 分片并发上传、多 P 投稿、线路选择（`--line`）、封面上传及原创/转载设置。
- 新增 `bt video append`：支持向已有稿件追加或更新分 P。
- 新增 `bt video studio ls` / `show`（别名 `archives`）：查看创作中心个人稿件列表与详情。

## 视频、番剧下载与互动

- 新增 `bt video download`（别名 `dl`）：支持 DASH / durl 多分片、语义画质 `-Q`、编码筛选 `-e h264/h265/av1`、纯音频 `.flac` 导出、备用 CDN 自动回退，以及自动附带 `.ass` / `.xml` 弹幕、字幕与封面边车文件。
- 新增 PGC 番剧（`ep` / `ss` / `md`）解析、流查看与下载支持。
- 新增视频详情（`info` / `streams` / `subtitle` / `summary` AI 总结 / `tags` / `related` / `danmaku`）与互动（`like` / `coin` / `triple` 一键三连）。
- 新增评论区完整读写：`video comments`（支持按热度/时间排序、`--root <RPID>` 楼中楼展开、`--full` 完整多行与 HTML 实体解码）及 `video comment post/like/delete`。
- 新增 `bt resolve` 通用链接/ID/短链解析命令。

## 直播、实时弹幕与录播

- `bt live start` 支持人脸核验（`60024` 二维码）、SRT 推流信息返回及 `-s` 完整推流码展示；新增全局 **`-D / --direct` 国内直连模式**（通过公共 DoH 与原生 IPv6 绕过本机代理/TUN 虚拟网卡，并输出 `OBS免代理地址` 与推荐绑定网卡）。
- 新增 `bt live chat`：终端实时 WebSocket 弹幕聊天室 TUI，支持看发一体、`/help` 斜杠命令及弹幕过滤。
- 新增 `bt live record` 增强：支持同步录制时间轴对齐的 `.ass` / `.xml` 弹幕（`--danmaku`）与 24/7 无人值守守候模式（`-w / --watch`、`--once`）。
- 完善 `live info` / `area` / `following` / `stream` / `danmaku` / `send`。

## 社区、个人数据与认证

- 新增 `bt search`（`video` / `user` / `live` / `hot`）、`bt rank`（`video` / `popular`）、`bt user`（`info` / `videos` / `dynamics` / `follow` / `unfollow`，不传 UID 默认当前账号）与 `bt feed`。
- 新增 `bt fav`（增删改查、失效清理与 CSV/JSON/文本导出）、`bt later`（稍后再看）与 `bt history`（游标分页、多前缀删除与清空）。
- 新增 `bt auth daily` 每日任务与直播签到；完善五种登录方式（Web/TV 扫码、短信、密码、Cookie）及 `buvid3`/`buvid4` 自动补全。

## CLI 工程化与补全

- 统一全局参数：`--json`（结构化 JSON 信封）、`-q/--quiet`、`-v/--verbose`、`-y/--yes`、`--no-color`、`-D/--direct`、`-u/--cookie-file`。
- `bt completions` 支持 Bash / Zsh / Fish / PowerShell / Elvish，支持自动识别 `$SHELL`，Zsh 下自动同步安装至 Oh My Zsh 自定义补全目录并清理旧缓存。
- 支持 `Ctrl+C` 优雅中断与临时文件清理；内置新版自适应宽度卡片/表格 UI 与 SVG README Banner。
