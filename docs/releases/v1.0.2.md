## 变更说明

### 1. 原生支持 Antigravity AI Agent 插件与技能体系 (Plugin & Skill)
- **Agent 插件化集成**：新增 `plugins/bili-tools` 规范化插件，内置完整的 `bili-tools` 技能定义（`skills/bili-tools/SKILL.md`）与安全规约（`rules/AGENTS.md`）。
- **一键安装体验**：支持通过 `agy plugin install https://github.com/qwerprog/bili-tools/tree/main/plugins/bili-tools` 远程安装或本地加载，赋予 AI 自动化操作 B 站全功能的能力（视频解析、AI 总结、字幕与弹幕下载、评论互动、直播录制与个人数据管理）。
- **安全与非交互规范**：全面统一遵循 `--json` 结构化信封协议，严格规范写操作确认机制与凭证保护，防范误触与凭证泄露。

### 2. 全链路命名规范化 (Standardized Naming)
- **核心命令命名对齐**：主命令与可执行文件全面规范为 `bit`（**Bi**li **T**ools），彻底弃用易与 BT 种子下载混淆的旧缩写 `bt`。
- **发行资产命名统一**：六大平台预编译二进制压缩包统一对齐为 `bit-v{version}-{platform}-{arch}.{ext}` 标准规范。
- **各大包管理器命名对齐**：
  - **WinGet**：统一包名标识 `QwerProg.bili-tools`，命令别名统一为 `bit`。
  - **Homebrew**：在官方 Tap 源提供 `bit` 配方（`brew install qwerprog/bili-tools/bit`）。
  - **AUR**：二进制包统一命名为 `bili-tools-bin`。

### 3. 清理废弃包配置与冗余产物 (Housekeeping & Cleanup)
- **移除废弃包源**：彻底清理并移除了已不再维护的 Scoop 相关旧配置，集中精力维护跨平台官方主流包管理器（WinGet、Homebrew、AUR）。
- **清理本地打包残留**：清理了此前构建 AUR 包时遗留的临时本地二进制产物（如 `pkg.tar.zst`、`.BUILDINFO` 等），大幅精简仓库历史与体积。

### 4. 安装指南与文档排版规范化
- **统一排版层级**：重构并统一了 `README.md` 的安装章节层级结构（各操作系统安装均为规范的三级标题 `H3`），纠正大小写命名（如规范 `WinGet` 官方拼写）。
- **用户引导前置**：将主流跨平台包管理器（Homebrew / AUR / WinGet）与 Releases 预编译二进制下载前置，源码编译后置，降低普通用户上手门槛。
