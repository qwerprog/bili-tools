## 登录

- 默认扫码登录改为 Web 登录，保留 TV 扫码作为备用选项。
- 修复 Web 登录成功后提示缺少 SESSDATA 的问题：完整读取多条 Set-Cookie 响应头，并兼容旧版 URL 凭据格式。
- 修复 TV 二维码过期后仍提示等待确认的问题；扫码等待约 3 分钟后退出，避免无限轮询。
- 二维码文件显示实际保存路径，并在登录流程结束后清理。

## 修复与可靠性

- 修复直播标题包含加号、与号、百分号等字符时被改写或截断的问题。
- HTTP 请求统一设置 30 秒超时，避免网络异常时长时间阻塞。
- 开播成功后优先输出并保存推流信息；统计标识缺失或保存失败单独提示，不再阻断推流信息输出。
- 下播成功后的统计查询失败仅显示警告，不再将已完成的下播返回为失败。
- 修复延迟下播参数乘法和累加溢出，以及倒计时边界处的减法溢出。
- 直播时长改为小时、分钟、秒显示；倒计时期间隐藏光标，结束或 Ctrl+C 中断后恢复。

## 本地数据保护

- Linux 和 macOS 上，配置目录限制为当前用户访问，Cookie、推流信息及二维码文件限制为当前用户读写。
- 访问配置目录时收紧旧版本敏感文件的权限。
- Cookie、推流信息和二维码使用临时文件写入后替换，避免写入中断损坏原文件。
- 保持现有 Cookie 文件格式和直播命令兼容，升级无需主动清除登录状态。

## 构建与验证

- 新增登录响应、多 Cookie 响应头、标题编码、文件权限、统计标识和延迟时间边界的回归测试。
- 发布包覆盖 Windows、macOS、Linux 的 x86_64 和 ARM64 架构。
- 所有平台构建成功后统一发布，并提供包含全部六个安装包的 SHA256SUMS。

## 安装与升级

### Cargo

在项目目录执行：

```bash
cargo install --path . --locked --force
```

### Arch Linux / AUR

```bash
yay -Syu bili-tools-bin
```

### macOS / Homebrew

```bash
brew update
brew upgrade QwerProg/bili-tools/bt
```

首次安装使用 `brew install QwerProg/bili-tools/bt`。

### Windows / Scoop

```powershell
scoop bucket add QwerProg https://github.com/QwerProg/bili-tools
scoop update
scoop update bt
```

首次安装使用 `scoop install bt`。

### Windows / WinGet

```powershell
winget upgrade --id QwerProg.bt --exact
```

WinGet 新版本需等待上游审核合并和源更新；审核完成前可使用本页安装包。
