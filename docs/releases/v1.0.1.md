## 变更说明

- **命令更名为 `bit`**：主二进制与命令行名称正式由 `bt` 升级为 `bit`（**Bi**li **T**ools），避免与 BT 种子下载工具混淆。
- **凭证目录无缝迁移**：数据目录迁移至 `~/.config/bit/`（Windows 为 `%APPDATA%/bit/`）；若首次运行未检测到新目录凭证，会自动兼容迁移旧 `bt/` 目录下的 `cookies.json` 与 `stream_info.txt`，无需重新登录。
- **统一 Release 产物命名**：六平台发行包统一采用 `bit-v{version}-{os}-{arch}` 命名规范（macOS/Windows 使用 `.zip`，Linux 使用 `.tar.gz`）。
- **文档与 CI 优化**：更新 `README.md` 与 SVG Banner 徽章至 `bit`；移除不再维护的 Scoop 配置，Windows 统一维护 WinGet；升级 GitHub Actions 至原生支持 Node.js 24 的最新版本。
